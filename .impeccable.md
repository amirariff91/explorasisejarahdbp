# Explorasi Sejarah — Design Context

## Project

Educational Malaysian history quiz game for DBP. Target audience: Malaysian secondary school students (Form 1–5). The game teaches Malaysian history through state-by-state exploration on an interactive map. Emotional goal: make learning Sejarah feel like an adventure, not a textbook.

## Platform & Constraints

- React Native / Expo — landscape-only
- Primary device: Android tablets + mid-range phones
- Offline-first (all assets bundled)
- BM (Bahasa Malaysia) primary language, English secondary

## Visual Identity

- Background: stylized Malaysian tropical landscape (desert/jungle warmth, orange/red tones)
- Board/card: parchment-style soalan-board with blue frame border
- State labels: red rounded badge top-left of board
- Buttons: dark brown rectangular with gold outline
- Timer: top-right, stopwatch icon
- Color palette: warm earth tones, gold accents, deep browns

## Design System (must preserve)

- Colors defined in `constants/theme.ts` → `Colors` object
- Font sizes via `getResponsiveFontSize(type, width)` from constants/theme.ts
- Spacing via `getResponsiveSizeScaled(n, width)` from constants/layout.ts
- Board sizes via `getQuestionBoardSize(type, width)`
- 4-tier responsive: phone / tablet-sm / tablet-md / tablet-lg

## Anti-patterns to Avoid

- No hardcoded hex colors — use Colors.* from theme
- No Dimensions.get() — use useWindowDimensions()
- No Platform.OS — use process.env.EXPO_OS
- No legacy shadowColor/shadowOffset/elevation — use CSS boxShadow
- No @expo/vector-icons — use expo-symbols
- No co-located components in app/ directory
- No console.log in production (use __DEV__ guard)
- No borderRadius without borderCurve: 'continuous'
- No numeric display without fontVariant: 'tabular-nums'
- No Pressable without accessibilityRole + accessibilityLabel

## Current Known Issues (from audit)

2. 33 Pressables missing accessibilityRole/accessibilityLabel
3. Legacy Animated (not Reanimated) in CountdownTimer, ScrollArrowIndicator, ScrollHintText
4. shadowColor/shadowOffset in StateCard (should be boxShadow)
5. Hardcoded hex colors in CountdownTimer, CongratsOverlay, GagalModal, GameTextInput
6. fontVariant: tabular-nums missing on timer and health/money counters
7. borderCurve: continuous missing on 32 borderRadius usages

## Motion & Feedback

- Question transitions: SlideInRight / SlideOutLeft (Reanimated)
- Correct answer: green flash + haptic + sound
- Wrong answer: red flash + haptic + penalty display
- State completion: CongratsOverlay with celebration animation
- All haptics via expo-haptics, iOS-only conditional
